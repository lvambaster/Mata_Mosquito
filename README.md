# 🦟 Mata Mosquito  

🚀 **Jogo desenvolvido para aprendizado de JavaScript puro, utilizando HTML, CSS e JS.**  

## 📌 Sobre o Projeto  
O **Mata Mosquito** é um jogo simples criado para aprimorar habilidades em **JavaScript puro**, manipulação do DOM e eventos. O objetivo é clicar nos mosquitos que aparecem aleatoriamente na tela antes que o tempo acabe.  

🔗 **Acesse o projeto:** [Clique aqui](https://lvambaster.github.io/Mata_Mosquito/)  

## 🛠 Tecnologias Utilizadas  
- **HTML5** → Estrutura do jogo  
- **CSS3** → Estilização e layout  
- **JavaScript (Vanilla JS)** → Manipulação do DOM, eventos e lógica do jogo
